HOW TO RUN — NetWatch Network Monitoring System
================================================

Quickest way (everything in one command, Docker required):
  docker compose up --build
    - Dashboard:      http://localhost:8080
    - API docs:       http://localhost:8000/docs
    - Login:          account from the users table

Local development (no Docker):

  1) Backend (Python 3.10+):
    cd backend
    python -m venv .venv
    .venv\Scripts\activate          (Windows)
    source .venv/bin/activate       (Linux/macOS)
    pip install -r requirements.txt
    uvicorn app.main:app --reload --port 8000

    Requires Supabase — there is no local database fallback. In backend/.env set
    DATABASE_URL (Supabase Postgres connection string, for users/auth) plus
    SUPABASE_URL / SUPABASE_SERVICE_KEY (Storage bucket for devices, alerts and
    the hourly traffic-history shards behind the Traffic page chart).
    The event bus runs in-memory unless REDIS_URL is set.

    Command for generating the SECRET_KEY for backend/.env
    python -c "import secrets; print(secrets.token_urlsafe(48))"

  2) Frontend (Node.js 18+):
     cd frontend
     npm install
     npm run dev
     Open http://localhost:5173  — login with an account from the users table

     The Vite server proxies /api and /ws to the backend automatically.
     All data comes live from the backend — there is no mock data.

Error checking:
  npm run lint
  npm run build
